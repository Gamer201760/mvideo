# Пакетная обработка и порог

`POST /api/v1/extract/batch` принимает от 1 до 100 карточек с уникальными `id`.
Лимит карточки — 24 000 символов, пакета — 240 000 символов текстовых полей.
Пакет использует `hybrid`; без ключа выполняется локальный алгоритм.

```json
{"items":[{"id":"sku-1","category_id":761,"title":"Смартфон","description":"Цвет: синий"}]}
```

Для каждого ID возвращаются `run_id`, `status`, `result` или `error`.
Порядок совпадает со входом. Временный сбой карточки не отменяет уже сохранённые
результаты остальных. При частичном успехе HTTP-статус 200; ошибка формата
всего запроса возвращает 422 до обработки.

`summary` содержит количество успешных и неудачных карточек, обращений к
провайдеру, карточек из правил, токенов и длительность. Обращение к локальному
алгоритму не является обращением к внешней LLM. Неизвестное число токенов — `null`.

## Ограничения нагрузки

| Настройка | По умолчанию | Значение |
|---|---:|---|
| `EXTRACTION_BATCH_SIZE` | 4 | Карточек в группе, диапазон 1–16 |
| `EXTRACTION_CONCURRENCY` | 2 | Одновременных групп, диапазон 1–8 |
| `EXTRACTION_MAX_BATCH_CHARS` | 48000 | Максимум символов JSON prompt |
| `EXTRACTION_MAX_PENDING` | 8 | Активных и ожидающих вызовов |
| `GATEWAY_TIMEOUT_S` | 120 | Таймаут основного вызова группы с ожиданием слота и повторами |
| `BATCH_PROXY_TIMEOUT_S` | 1800 | Ожидание пакетного ответа в nginx |
| `RULES_FIRST` | true | Пропуск модели для достаточного результата правил |

Ограничение prompt не включает system и схему ответа. Текст не обрезается:
слишком большая карточка получает `model_input_too_large`.
Переполненная очередь возвращает `model_capacity`.

Для N карточек, требующих модели, размер группы B и параллелизм C дают примерно
`ceil(ceil(N / B) / C)` волн. Ограничение размера текста может увеличить число
групп. При изменении настроек согласуйте таймауты клиента и nginx.

После отказа шлюза локальный резервный этап получает отдельный бюджет:
не больше 10 секунд и не больше `GATEWAY_TIMEOUT_S`, включая ожидание слота.
При включённом `GATEWAY_FALLBACK` это время добавляется к основному вызову.
Одиночный API-запрос nginx ожидает до 240 секунд: это покрывает максимальные
180 секунд основного вызова, резервный этап и сохранение результата.
Пакетный запрос использует отдельный `BATCH_PROXY_TIMEOUT_S`.

Это синхронный API одного backend-процесса с SQLite. Распределённая очередь
и исполнение на нескольких узлах в текущий релиз не входят.

## Автопринятие

`ACCEPTANCE_THRESHOLD=0.95` и `AUTO_ACCEPT=true` — значения по умолчанию.
Автоматическое принятие требует одновременно валидного свидетельства,
низкого риска, достаточного балла и разрешённого автопринятия.
`AUTO_ACCEPT=false` действует и для `rules`, и для `hybrid`.

Балл является эвристикой, а не вероятностью правильности. Отсутствующие,
противоречащие или неопределённые сведения не заполняются высоким баллом.
Человек может подтвердить, изменить или отклонить значение; его решение
сохраняется отдельно и не теряется при повторном извлечении.
