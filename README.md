# Атрибуты товаров

Извлечение характеристик из карточки продавца: regex → RAG → LLM.
Результат: категория, нормализованные значения, цитаты и числовой балл подтверждения.
Высокий балл сопровождается причинами: точная цитата, подтверждённое значение,
совпадение числа и единицы, соответствие поля категории.

Целевая LLM-конфигурация: `ai-sage/GigaChat3.5-432B-A28B-Reasoning` через шлюз.

## Запуск

Нужны Docker и Docker Compose v2.

```bash
docker compose up --build -d
```

Интерфейс: http://localhost:8080.
Для шлюза создайте `.env` с `GATEWAY_API_KEY=ваш_ключ`. Ключ в Git не добавляется.
Без ключа выполняются regex и локальный поиск категории.

Выберите синтетический пример или вставьте карточку, нажмите «Извлечь атрибуты».
Откройте цитату. Для правки нажмите карандаш рядом со значением в таблице
и «Сохранить». Правка применяется без повторного извлечения.
Пропущенное поле можно добавить вручную с цитатой из карточки.
Неверное значение можно отклонить, а затем восстановить.
Правки и новые категории сохраняются в SQLite.

Остановка: `docker compose down`.

## Проверки

Проверены запуск Compose на чистом томе, извлечение с цитатами, пропуски,
исправление и повторное извлечение, атомарность и сохранение SQLite после перезапуска.
Браузерные проверки охватывают русский и английский языки, обе темы и сквозной сценарий.
Для автоматических проверок настроен GitHub Actions.

[Документация](docs/README.md) · [Backend](backend/README.md) · [Frontend](frontend/README.md)

Для массовой загрузки есть [пакетный API](docs/scaling.md): ограниченные группы,
параллелизм и результат по каждому ID. Порог принятия по умолчанию — 95/100;
балл подтверждения является эвристикой. Решение человека хранится отдельно.
