# Данные и EDA

## Исходные данные

Публичная копия содержит код подготовки и анализа; данные организаторов
и готовые предсказания распространяются отдельно в закрытом репозитории команды.
Его архив состоит из 38 gzip-частей в `artifacts/source/parts` размером не более
32 MiB. `artifacts/source/manifest.json` содержит имена, размеры
и SHA-256 каждой части и каждого восстановленного оригинала.
Общий размер частей — 1 223 580 474 байта; после восстановления — 2 568 187 871 байт.
Для воспроизведения в публичной копии сначала получите три оригинала у организаторов
либо архив из закрытого репозитория.

| Оригинал | Размер, байт | Содержимое |
|---|---:|---|
| `sku_desc.parquet` | 352 149 681 | Названия и описания товаров |
| `query_clicks.parquet` | 650 887 879 | Поисковые запросы и клики |
| `skus.pkl` | 1 565 150 311 | Каталог товаров, категории и параметры |

Из корня репозитория, Python 3.10+. Если у вас оригинальные файлы, создайте архив;
при наличии готового архива этот первый шаг не нужен:

```bash
python3 scripts/package_dataset.py --source /path/to/raw --output artifacts/source
python3 scripts/verify_dataset.py
python3 scripts/restore_dataset.py --output data/raw-v1
```

Проверка проходит по всем частям, gzip CRC и контрольным суммам оригиналов.
Восстановление читает pickle как непрозрачные байты и не исполняет его содержимое.
Неизвестные части, небезопасные пути, символические ссылки и повреждения приводят
к явному отказу. Существующее назначение и незавершённый каталог не перезаписываются.
Проверка и восстановление используют ограниченные буферы, не загружая исходники целиком в память.

Основной интерфейс запускается на встроенном каталоге `backend/seeds`.
Для короткой проверки через API используйте синтетический пример из
[README](../README.md#быстрая-проверка-api). Реальные проверочные карточки
и их предсказания не публикуются в открытой копии.

## Полное воспроизведение

```bash
bash scripts/reproduce_case.sh data/reproduced-v1
```

Одна команда восстанавливает исходники, готовит parquet, выполняет EDA,
строит полный baseline правилами и проверяет предсказания. Все результаты
появляются в новом каталоге `data/reproduced-v1`; исходники репозитория
и ранее полученные результаты сохраняются. [Требования и выходы](reproducibility.md).

Подготовка создаёт карточки, gold, схемы, клики, разбиения и обязательные поля.
Вход извлечения содержит название, описание и параметры продавца.
Gold из `*_search` и каталожных бренд/модель хранится отдельно и не передаётся
в запрос извлечения. Обязательные поля выводятся из каталога и трафика
по эвристике. `processed/manifest.json` фиксирует исходные и выходные
хеши, настройки и количество строк.

## Полные предсказания

Baseline правилами содержит запись для каждой из 1 481 914 подготовленных карточек.
Манифест полного результата, создаваемый вместе с выгрузкой,
связывает входы, сжатые части и их SHA-256.
Проверка фиксирует полноту ID, порядок, соответствие входному тексту и позиции цитат
в `verification.json`. Пустые результаты, неизвестная категория и ошибки имеют
явные статусы и сохраняются в наборе.

Этот запуск проверяет полноту исполнения на всём наборе и воспроизводимость правил.
Он не является независимой оценкой точности внешней модели или калибровки балла.
