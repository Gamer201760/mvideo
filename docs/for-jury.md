# Маршрут проверки

1. Запустите приложение по [инструкции](../README.md) и откройте интерфейс.
2. Выберите пример карточки и нажмите «Извлечь атрибуты».
3. Во время обработки посмотрите кандидатов категорий. В результате останется выбранная категория.
4. Проверьте значения, числовые баллы подтверждения и причины оценки. Откройте цитату в исходном тексте.
5. Проверьте порог принятия над результатом. «Принято по порогу» означает автоматическое принятие; «Подтверждено» — решение человека. Измените значение прямо в таблице: Enter или выход из поля сохраняет, Escape отменяет ввод. Строка обновится без нового извлечения. Кнопка «Отклонить» убирает значение из результата; блок «Отклонено вами» позволяет восстановить его. Для значения на ручной проверке можно нажать «Подтвердить».
6. В блоке «Правки текущей карточки» раскройте «Добавить значение» для пропущенного поля. Введите значение и скопируйте дословную цитату из исходного текста. Сохраните: поле появится как ручное решение, без выдуманной уверенности модели.
7. Нажмите кнопку отклонения рядом со значением. Оно исчезнет из заполненных полей и появится в списке «Отклонено вами». «Восстановить» вернёт значение как решение человека. Счётчик показывает оставшиеся значения на проверке.
8. Обновите страницу: черновик или последний результат восстановится без нового извлечения. Перезапустите приложение: исходные карточки, результаты и решения останутся в SQLite.
9. Нажмите «Назад»: под формой появится история извлечений и запросы в работе. Откройте завершённую запись: результат загрузится без вызова модели, с актуальными решениями.
10. Нажмите «Скачать JSON» в результате или у завершённой записи истории. Откройте файл: исходный ввод, категория, значения с цитатами и ручные решения должны соответствовать выбранной карточке. Отклонённые значения отсутствуют в заполненных полях; их решения есть в `decisions`.

Для проверки пропусков удалите из карточки одно из обязательных значений.
Для проверки новой категории через шлюз вставьте описание товара вне начального каталога
с явно указанными характеристиками.
