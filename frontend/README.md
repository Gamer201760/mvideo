# Frontend

React, TypeScript и Vite. Интерфейс получает категории, характеристики, цитаты
и очередь проверки из API. Поддерживаются русский и английский языки, две темы.

Для разработки нужны Node.js 22.18+ и запущенный backend на порту 8000.
Команды выполняются в `frontend/`.

```bash
npm ci
npm run dev
```

Адрес интерфейса выводится в терминале. Другой адрес backend задаётся через `API_URL`.

## Проверки

```bash
npm run verify
npx playwright install chromium
E2E_BASE_URL=http://localhost:8080 npm run e2e
```

Браузерный сценарий выполняется на приложении, запущенном через Compose без ключа
шлюза. Он проверяет извлечение, пропуски, исправление и повторное извлечение.
