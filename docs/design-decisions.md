# Решения реализации

## Проверка результата

`rules` и `hybrid` используют общую политику принятия. Перед ней проверяются
структура ответа, категория, принадлежность поля схеме, точная цитата,
отрицания, объект характеристики, числа, единицы и диапазоны.
Неопределённое или приблизительное утверждение нельзя превратить в точное.
Канонизация значения сохраняет исходную цитату и её позиции.

Неподтверждённое значение попадает в `rejections`, а поле остаётся незаполненным.
Увеличение уверенности не отменяет проверку свидетельства.
Балл подтверждения — эвристика из признаков текста; `AUTO_ACCEPT=false`
отправляет все новые значения на ручную проверку.

## Хранение

SQLite хранит категории, исходные карточки, запуски с JSON результата,
решения проверки и алиасы. Контроллер извлечения создаёт запись запуска,
исполняет сценарий и сохраняет завершённый результат. История читает этот
результат без повторного вызова модели.

Unit of Work задаёт транзакцию записи. Решение человека и соответствующий
алиас записываются атомарно. Отклонение не создаёт алиас.
Чтения используют отдельные read-only транзакции и не требуют блокировки писателя.
Ошибки драйвера преобразуются в безопасные доменные ошибки.

## Обратная связь

Решения связаны с полным текстом карточки, категорией и параметрами продавца.
Они применяются при повторной обработке этой карточки в обоих режимах.
Ручное решение не заменяется автоматическим результатом. Конфликтующая
повторная правка возвращает 409; повтор одинаковой правки идемпотентен.

Снимок результата в истории сохраняется. Интерфейс и экспорт сверяют его
с актуальными решениями и показывают исправленные или отклонённые поля.
[Контракт экспорта](export.md).

## Параллелизм и конфигурация

Сетевые операции и SQLite асинхронные. Поиск, разбор ответа и проверка
свидетельств выполняются вне event loop. Размер группы, число одновременных
обращений, очередь и время ожидания ограничены настройками.
Пакет сохраняет связь результата с входным ID и изолирует сбой карточки.

Конкретные реализации собираются в `main.py`. `Any` используется только для
JSON Schema и внешнего JSON, где структура проверяется до доменного разбора.
Каталог процесса обновляется после сохранения новых категорий и полей;
распределённая синхронизация нескольких backend-процессов не реализована.
