# Воспроизводимость

## Приложение

Из корня чистой копии:

```bash
docker compose up --build -d --wait
```

Нужны Docker Compose v2 и доступ к реестрам образов и Python/npm-пакетов при первой сборке.
Без `.env` запускаются локальные правила, поиск категорий, SQLite и интерфейс.
Синтетический демо-каталог входит в `backend/seeds`. Данные организаторов,
реальные проверочные карточки и готовые предсказания в публичную копию не входят.
Приложение не читает соседние рабочие копии или домашний каталог разработчика.

Интерфейс: http://localhost:8080. Готовность: http://localhost:8080/api/v1/ready.
Остановка: `docker compose down`. Именованный том SQLite сохраняется.

Для отдельного стенда без ключей:

```bash
COMPOSE_PROJECT_NAME=mvideo-check FRONTEND_PORT=8081 BACKEND_PORT=8002 \
  GATEWAY_API_KEY= OPENAI_API_KEY= docker compose up --build -d --wait
```

## Полный набор, EDA и предсказания

Нужны Python 3.10+ на хосте и Docker Compose v2. Для полного расчёта выделите
8 GiB памяти и не менее 16 GiB свободного места. Сначала получите три исходных
файла у организаторов и создайте локальный архив по [инструкции](data.md).
Либо поместите полученный из закрытого репозитория архив в `artifacts/source`.
После этого из корня репозитория:

```bash
bash scripts/reproduce_case.sh data/reproduced-v1
```

Команда проверяет локальные части архива и восстанавливает три оригинала,
собирает backend, готовит parquet-набор, выполняет EDA и вычисляет полный
baseline правилами с двумя работниками. Последний этап проверяет все ID,
порядок записей, цитаты и контрольные суммы файла предсказаний.
Проверка запускается с `--write-receipt` и сохраняет `verification.json` один раз.
Ограничение числа карточек не используется. Вызовов LLM нет; ключи шлюза
не передаются контейнеру обработки данных.

| Результат в `data/reproduced-v1` | Содержимое |
|---|---|
| `raw/` | Точные исходные parquet и pickle с проверенными SHA-256 |
| `processed/` | Карточки, gold, категории, разбиения, клики и манифест |
| `eda.ipynb`, `eda.json`, `figures/` | Выполненный notebook, сводка и графики |
| `predictions/` | Сжатые предсказания всех карточек, манифест и `verification.json` |

Назначение должно быть новым относительным каталогом внутри `data/`.
Для имён используйте латинские буквы, цифры, точки, дефисы и подчёркивания;
каждый сегмент начинается с буквы или цифры.
Существующие результаты, символические ссылки и незавершённые каталоги
не перезаписываются. При отказе сохранённые файлы остаются для диагностики;
для нового запуска выберите другое имя. Установленные зависимости и кеш
инструментов хранятся отдельно в `.local/`.

Полный baseline охватывает 1 481 914 карточек и проверяет исполнение правил
на всём подготовленном наборе. Это не независимая оценка качества модели.
Состав исходников и отдельные команды: [данные и EDA](data.md).
Проверка небольшого набора через основной API: [предсказания](benchmark.md).

Сохранённая в закрытом репозитории проверка `artifacts/reproduction/verification.json`
фиксирует запуск на macOS и Linux: все семь подготовленных Parquet-файлов
совпали по SHA-256; EDA выполнен на обеих платформах. Архив также восстановлен
штатным Python 3.10 ВМ.
Первые 1000 предсказаний независимо пересчитаны на Linux и побайтно совпали
с началом полного запуска на macOS; порядок ID и каталог также совпали.

## Переносимый пакет

```bash
python3 scripts/export_release.py --output /tmp/mvideo-package
python3 scripts/export_release.py --verify /tmp/mvideo-package
```

Пакет содержит исходники приложения, lock-файлы, миграции, seed, документацию и EDA.
Если рядом локально находятся `artifacts/` и `examples/`, экспорт также включает их
содержимое. Такие пакеты с данными кейса предназначены для закрытого контура.
`release-manifest.json` фиксирует SHA-256. Локальные базы, восстановленные
копии `data/`, установленные зависимости и кеши в пакет не включаются.
Существующая директория назначения не перезаписывается.

## Диагностика

| Симптом | Проверка |
|---|---|
| Порт занят | Задайте свободные `FRONTEND_PORT` и `BACKEND_PORT` |
| Ошибка миграций | `docker compose logs migrate seed` |
| API не готов | `docker compose ps` и `docker compose logs backend` |
| Шлюз недоступен | Проверьте адрес, имя модели и ключ; локальный результат содержит `fallback_reason`, иначе возвращается код ошибки |
| Повреждён архив исходников | `python3 scripts/verify_dataset.py` |
| Назначение уже существует | Выберите новый каталог `data/<имя>` |

`/api/v1/health` проверяет процесс, `/api/v1/ready` — каталог и обязательные
таблицы SQLite. Проверка готовности не вызывает внешнюю модель.
