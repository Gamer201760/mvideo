# Когда вызывается модель

`RULES_FIRST=true` включает проверку достаточности результата правил.
Вызов модели пропускается, если выбрана известная категория, поиск достаточно
однозначен, все обязательные поля найдены и каждое подтверждено проверками.

Карточки, которым нужна модель, объединяются в исходном порядке в группы
с общим словарём схем и ограничением размера запроса. При отсутствии ключа модельный порт выполняет локальные правила.
При наличии ключа используется явно настроенный шлюз и имя модели.
После исчерпания повторов при недоступности, перегрузке или таймауте шлюза
выполняются локальные правила. Ответ содержит `fallback_reason`, а интерфейс
показывает «Результат локальных правил». Частичный результат проходит обычные
проверки цитат, нормализации и порога; пропущенные поля остаются незаполненными.
Реальные попытки обращения к шлюзу сохраняются в статистике пакета.
Основной вызов ограничен `GATEWAY_TIMEOUT_S`, локальный переход после отказа
получает не более 10 секунд. Одиночный запрос через nginx допускает до 240 секунд.

`GATEWAY_FALLBACK=false` отключает этот переход. Некорректный JSON или схема
ответа остаются явной ошибкой `invalid_model_output`; автоматическая замена
таких ответов не скрывает нарушение контракта.

Пропуски остаются пропусками. Ручные решения применяются отдельно после
извлечения. Порог принятия одинаков для обеих веток.
