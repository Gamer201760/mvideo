# Проверки

## Backend

Нужны Python 3.12+, uv и dbmate 2.36.0. Из `backend/`:

```bash
uv sync --locked
uv run ruff check .
uv run ruff format --check .
uv run mypy .
uv run pytest tests/unit tests/integration -q
```

Если dbmate отсутствует в PATH, задайте `DBMATE_BIN`.
Интеграционные тесты применяют настоящие миграции к временной SQLite.
Проверяются сохранение истории и ручных решений, атомарность, конкурирующие
операции, ограничения категорий, валидация цитат и изоляция сбоев пакета.
Ошибки провайдера проверяются через HTTP-транспорт без платных вызовов.

Сохранённая в закрытом репозитории проверка `artifacts/smoke/gateway.json` содержит один сквозной запрос
к реальному шлюзу: значения с точными цитатами, пропущенный аккумулятор и
совпадение истории после перезапуска. Отдельный локальный HTTP 503 подтверждает
две попытки, явный fallback и фактический порядок событий контейнерного журнала.
Один синтетический вход проверяет интеграцию; точность на каталоге им не измеряется.

## Frontend

Нужны Node.js 22.18+ и npm. Из `frontend/`:

```bash
npm ci
npm run verify
npx playwright install chromium
E2E_BASE_URL=http://localhost:8080 npm run e2e -- --workers=1
```

Браузерные тесты запускаются на отдельном Compose-проекте без ключей шлюза.
Для проверки настоящего перезапуска backend задайте `E2E_COMPOSE_PROJECT`.
Тесты охватывают извлечение, цитаты, ручную правку, отклонение, восстановление,
историю, экспорт и доступность RU/EN в обеих темах.

## Предсказания

[Команда повторной обработки](benchmark.md) использует основной API и сохраняет
результат или явную ошибку каждого входного ID. Готовые файлы предсказаний из
закрытого репозитория получены локальными правилами; публичная копия содержит
код их построения. После получения данных полная выгрузка проверяется по каждому входному ID,
контрольным суммам всех частей и точным диапазонам цитат:

```bash
docker compose --profile tools run --rm --no-deps --user "$(id -u):$(id -g)" \
  dataset python -m batch_predict.verify --data /workspace/data/reproduced-v1/processed \
  --output /workspace/data/reproduced-v1/predictions
```

Команда проверки не изменяет выгрузку и допускает повторный запуск.
Флаг `--write-receipt` сохраняет `verification.json` и его контрольную сумму
в манифест; существующая квитанция не перезаписывается. Технические тесты и исполнение набора
не измеряют точность внешней модели или калибровку уверенности.
